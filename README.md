## Projetos e laboratórios

### MTScan

[![Repository](https://img.shields.io/badge/GitHub-MTScan-181717?style=flat-square&logo=github)](https://github.com/LuccaVG/MTScan)

Toolkit de análise de vulnerabilidades para Linux que integra ferramentas da ProjectDiscovery.

**Tecnologias e recursos:**

- `naabu`
- `httpx`
- `nuclei`
- Python
- Linux
- CLI
- Aplicação web local
- Histórico de scans
- Relatórios de vulnerabilidades
- Cassandra / armazenamento local

Fluxo principal:

`naabu → httpx → nuclei`

O projeto permite execução pela linha de comando e por uma interface web local, com geração de relatórios contendo severidades, achados prioritários, contexto de exposição e informações de remediação.

---

### PQC-overhead on MQTT/TLS

[![Repository](https://img.shields.io/badge/GitHub-pqc--mqtt--benchmark-181717?style=flat-square&logo=github)](https://github.com/LuccaVG/pqc-mqtt-benchmark)

Benchmark voltado à análise de desempenho de **MQTT sobre TLS** e overhead associado a algoritmos de **criptografia pós-quântica**.

**Tecnologias e conceitos presentes no repositório:**

- MQTT
- TLS
- ML-KEM
- ML-DSA
- liboqs
- Docker Compose
- QEMU
- ARM64
- Linux

O ambiente permite simular `linux/arm64` em hosts AMD64 e realizar medições relacionadas a conexão MQTT/TLS, publicação e operações criptográficas.
